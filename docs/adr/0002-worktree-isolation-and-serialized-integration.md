# Isolate PBI implementation and serialize integration

Each issue implemented concurrently in a round uses a dedicated Git worktree and branch so parallel implementers do not share a working directory. Gantry integrates those branches into the run branch one at a time, running the declared gates after each merge, and a red gate after a merge stops the run rather than being fixed forward by the orchestrator. This preserves parallel implementation while avoiding shared-checkout interference and stale approvals, at the cost of worktree lifecycle management and repeated validation as the target advances.
